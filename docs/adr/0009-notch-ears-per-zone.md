# 耳区按分区自定内容，中央禁放区只画背景

物理挖槽挡住的中间必须空，但两边耳区是正常屏幕；整条留白导致顶部空一大片。将旧「刘海安全区」拆为中央禁放区（挖槽宽＋边距，高＝刘海高＋8pt，只画背景）与耳区（两边可用，各分区自定单行内容、超长截断，高度跨页保留）；现定概览页耳区留空、Token 页左耳总量加命中率右耳调用次数，并删 Token KPI 行、右上齿轮（设置只走右键）、概览页暂存盘（只留额度块居中）。

## Considered Options

- 整条安全区延续留白：实现最少，但顶部空白难看，否决。
- 耳区全局固定一套：切页不跳，但各页想放的不一样，否决。
- 字段搬进耳区后保留 KPI 行：信息重复且占高，否决。

## Consequences

- 新分区必须自备耳区内容并遵守单行截断；切页耳区高度不变。
- 跟进任务（与本 ADR 同一工单）：切页时额度环大数字闪一下残影；双指右键菜单（设置／退出）弹出很卡，需优化。
