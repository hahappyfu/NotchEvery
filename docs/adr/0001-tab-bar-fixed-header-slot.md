# 选项卡钉死：头部槽位移出高度动画作用域

分区面板高度随分区查表变化（概览 160、设置 280），而面板 `.frame(600, h)` 默认垂直居中其内容，各区内容自然高度不同，导致顶栏选项卡垂直位置随分区漂移，被切换弹簧的过冲放大成肉眼可见跳动（2026-09-07 用户录屏确诊）。我们决定把选项卡所在的头部槽位移出高度动画的作用域：面板结构固定为「28pt 头部槽 + 仅内容区随高度表动画」，并保留切换时的过冲弹簧——弹性生动机是想要的手感，位移源必须由结构保证为零而不是靠内容恰好撑满面板。配套 Debug 断言 + Release 裁剪兜底「高度表与内容脱节」（等高实验证明脱节时选项卡会被静默顶出面板）。

## Considered Options

- 最小改动（frame 加 `.top` 对齐）：被否——「内容必须撑满」仍是不变量，设置区加一行即复发。
- 等高面板 + 设置区滚动：被否——推翻刚定稿的设置区排版。
- 内容驱动高度（删高度表）：被否——设置项展开时面板二次跳动，违背「高度查表」的既有测试契约。

## Consequences

- 选项卡垂直恒定成为结构性质，未来新增分区只需在高度表加条目，选项卡自动安全。
- 内容区可用高度 = 分区高度 − 28 − 间距×2，新增设置行前先对照高度表，Debug 断言会兜底。
