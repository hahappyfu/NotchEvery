# Nook 风外观与骨架：跟随系统深浅色、抄 Nook 骨架、微调弹簧

用户提供 Nook 录屏（纯黑半透明面板 + 黑胶囊选项卡 + 虚线文件托盘）与现状录屏（浅灰双卡）对比，要求前端交互向视频靠拢。经六题访谈（2026-09-08，用户逐题亲选），决定：面板与选项卡跟随系统深浅色自动切换；概览区骨架抄 Nook（左媒体式大图标、右信息列表，填配额与托盘功能）；选项卡照搬 Nook 款（胶囊带图标、右侧齿轮）；托盘空态改为虚线大框；展开/切换弹簧微调向视频手感对齐；概览与设置两区一起改。

## Considered Options

- 纯深色（不跟随系统）：被否——用户亲选跟随系统。
- 保留双卡只换皮：被否——用户亲选抄 Nook 骨架。
- 动画不动：被否——用户亲选微调弹簧参数。
- 只改概览区：被否——两区风格不一致，比现在更丑。

## Consequences

- 深浅两套配色都要自查对比度，语义色（`.primary` 等）靠系统环境自动适配，不再强制深色环境。
- 骨架重排可能触动高度表与选项卡钉死契约，改动前先对照高度表，Debug 断言兜底。
- 宽度 600pt 锁定不动；弹簧调参单独验证手感。
- 注意：上一轮"我代选"期间曾把 `NotchTabBar` 改成深色硬编码，与"跟随系统"冲突，动手时须改回自适应。
