# 控制中心质感（深色底）设计规格

日期：2026-09-07｜方案：A（深色底 + 新质感）｜范围：虚影小黑框 + 展开面板（含额度卡与文件暂存区）

## 目标

对齐 macOS 控制中心的冻玻璃质感——大连贯圆角、宽松留白、细描边高光。
深色沉浸底不变，不切材质（Liquid Glass 不引入），不重排布局。

## 现状数值（改前）

| 位置 | 值 |
|---|---|
| 卡片圆角 `vm.cornerRadius` | 16（额度卡、暂存区共用） |
| 面板内边距/间距 `vm.spacing` | 16（VStack/HStack/padding 共用；mask 切角几何也引用） |
| 外壳/虚影描边 | 白 0.08，1pt |
| 暂存区描边 | 白 0.12（闲置）/ 0.3（拖拽指向） |
| 轨道/占位/虚线环 | `separatorColor`（已落地，保持） |
| 阈值三色 | 系统绿/橙/红（深色底可读，保持） |
| 材质 | ultraThinMaterial + 深色底（保持，不动） |

## 改动（只改 4 个数，两处描边）

1. `vm.cornerRadius` 默认值 16 → 20（额度卡、暂存区同步变大圆角）。
2. `vm.spacing` 默认值 16 → 20（面板留白拉开；mask 切角几何同源跟随，无需另改）。
3. 外壳与虚影描边白 0.08 → 0.14（`NotchView` 玻璃背景 overlay）。
4. `glassCard` 非 26 系统回落路径加同级描边（白 0.12），与暂存区闲置态对齐；26+ 走 `glassEffect` 自带边缘光，不加。
5. 不改：材质、阈值三色、字体字阶、布局结构、动画参数。

## 成功标准

- 构建通过（scheme 姿势）。
- 截图对比：虚影与展开面板圆角更大、留白更松、边缘有淡高光；深色底与动画手感与改前一致。
- 动画无回归：未动材质与驱动，帧成本零新增（无需重采样，有体感即过）。

## 范围外（另案）

- 配额读真实家目录根治（`getpwuid`，容器播种过期后复现）。
- 虚影态旁路阴影/材质的渲染降级。
