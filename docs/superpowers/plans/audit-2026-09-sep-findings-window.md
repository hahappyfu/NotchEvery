# 审计发现存档：窗口/事件/系统交互层（reviewer-window）

> 中间存档；最终汇总见总报告。36 文件全审 + 调用链交叉验证。

## Critical
- **C1** NotchView.swift:131-137 方向键切区空壳：onReceive(arrowKey) 四重守卫后只调 markSwipeHintSeen()，无任何切区调用；全仓库 grep 确认 arrowKey 仅此一消费点。副作用：无效按键会把 hasSeenSwipeHint 置 true，横扫提示被永久吞掉。EventMonitors.swift:85-94 为它开的全局 keyDown 监听白白承担 AX 权限监听面。（与 UI 层 Critical#3 同一问题，交叉确认）
- **C2** TrayDrop.swift:144-151 cleanExpiredFiles 只清集合不删文件：过期分支（TrayDrop+DropItem.swift:152-153）的 storageURL 文件与 preview PNG 永久滞留 ~/.notchevery/CopiedItems/。用户设 1 Hour 保留期但文件永不销毁——磁盘+隐私双重泄漏（用户以为删了其实还在）。修复一行：循环加 removeFiles(of:)。

- I3 main.swift:95-97 后台线程写 @Published（cleanExpiredFiles → items= → objectWillChange 后台触发未定义行为）。修复：赋值 hop 回主线程。
- I4 EventMonitors.swift:63-94 全局 keyDown 依赖 AX 权限，无授权时静默失效（monitor 创建成功但收不到事件）；C1 修复后此问题立即浮现，且 AX 授权后具备读所有按键能力，PermissionGuide 应明示。
- I5 ClipboardPaster.swift:95-111 paste 先 clearContents 再写，image 分支失败时剪贴板被清空、原内容覆盖性丢失。应先构造数据再 clear。

- I7 Ext+FileProvider.swift:100-118 interfaceConvert 部分失败丢整批+临时文件泄漏；TrayDrop.swift:80-92「逐个容错」注释宣称的修复永远走不到（下层已 return nil）；8s 超时后回调仍执行拷贝白做。
- I8 FUnlock 子系统整链未接线（死代码群）：InputActivityMonitor 零调用方、SecurityService↔SystemInteractionService↔SystemEffects 无上游、iMessageNotifier.sendTestNotification 无 UI 入口、SignalPipeline 零调用（仅 UnfairLock 被复用）。高权限路径以死代码形态随包分发，攻击面+审计负担。建议先决策去留再修。
- I9 lowlevel.c:26 CFNumber 每次唤醒泄漏；wakeAssertionID（:6,11-37）跨线程无锁竞态（double-release 或泄漏 assertion=显示器永不休眠）；funlock_wakeDisplay 无超时兜底。
- I10 LEDeviceInfo.swift:5-25 全局 SQLite 句柄竞态（inited/db_paired/db_other 无锁）；sqlite3_open 失败路径不 close。当前死代码，接线即隐患。
- I11 PublishedPersist.swift:16-17 全局共享 JSONEncoder/Decoder 并发使用（Foundation 未保证线程安全）；拖文件落盘与设置变更落盘并发即触发。
- I12 DebugLog.swift:28-44 每条日志开关文件一次（TimingLog 有句柄缓存先例）；debug.log 无轮转无限增长。

## 优点（供汇总）
- EventMonitor deinit→stop 成对移除干净；EventMonitors 单例只 init 一次、destroy 幂等
- closeToGhost ghostGeneration 代际防护 + scheduleHoverClose 先 cancel 旧 work item
- 窗口重建路径完整（didChangeScreenParametersNotification→rebuild→destroy）
- PID 单例加固：O_EXCL|O_NOFOLLOW、lstat 拒 symlink、flock 竞态、DispatchSource cancel 时 close fd
- 拖入安全：文件名消毒+二次防穿越、lstat 双重拒 symlink、2GB 上限
- ScrollSwipeResolver 垂直主导立即重置累积量
- SystemInteractionService 注入安全链：isSecureCheck 复核、AppleScript 仅 ASCII、日志 fileMsg/osMsg 分离脱敏
