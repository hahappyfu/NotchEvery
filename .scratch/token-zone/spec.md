# Token 分区 spec（定稿：用户紧凑版 HTML，2026-09-08）

## 目标
刘海面板新增第三分区 Token，与概览/设置并列切换，展示模型请求记录。首版 mock 数据，数据源后接。

## 范围（做）
- 新分区 `ContentType.token`，Tab 标题 "Token"，进 `zoneOrder` 三区循环（顶栏点击/横扫/方向键语义自动跟随）。
- KPI 单行：Tokens / 缓存率 / 调用 / 成本，32px 级胶囊，mock 聚合值（38.8M / 94.6% / 527次 / $0.00）。
- 请求表格 5 行 × 6 列：时间 / 模型 / 入/出 / 用时 / 成本 / 状态丸（200 绿底、≥400 红底，沿用 `ringColor` 阈值语言；缓存行带 ⚡︎ 标）。
- 高度表加 `.token` 条目，实测后定值；`hostedViewHeight` 取 max 重算；守卫不断言。
- Tab Bar 加第三段；现有两区零回归。

## 不做
- 趋势图、Provider/模型统计页。
- 数据源接入（本地日志扫描 vs API 轮询另起工单，mock 模型预留替换缝）。
- 原型特效：呼吸灯、`+模拟`按钮、视图切换（表格⇄极简行）延后；Tailwind/CDN/外链字体不进工程，用系统字体。
- 宽度保持 600 锁定，不跟原型的 520。

## 成功标准
1. 三区切换，选项卡位置恒定，窗口高度跟随 token 区。
2. Debug 下切到 token 区守卫不断言；5 行表格列不溢出 600 宽。
3. `zonePanelHeight[.token]` 有表值测试锁定。
